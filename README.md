# Sistema de Caja para Tienda

## Descripción del Proyecto
Este es un programa de consola desarrollado para atender la caja de una tiendita de barrio. Actualmente, el sistema cuenta con un menú iterativo que permite registrar ventas, pedir precios y cantidades de productos uno por uno hasta ingresar un 0, y calcular el subtotal de la compra acumulada. También incluye validaciones para evitar el ingreso de precios negativos o cantidades fuera del rango permitido.

## Lenguaje Utilizado
* C++

## Cómo Compilar
En la terminal con el compilador `g++`, el comando para compilar el archivo fuente:
`g++ main.cpp -o caja`

*(Si usas un programa como Dev-C++ o CodeBlocks, basta con presionar el botón de "Compilar" o F9).*

## Cómo Ejecutar
Una vez que el código esté compilado, puedes iniciar el programa en la consola dependiendo de tu sistema operativo:
* **En Windows:** Escribe `caja.exe` en la terminal o haz doble clic en el archivo generado.
* **En Linux / Mac:** Escribe `./caja` en la terminal.
